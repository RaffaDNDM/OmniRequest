# OmniRequest
A modern, self-hosted web utility built with Flask to instantly convert raw HTTP requests into 14+ programming languages and networking libraries (including JavaScript Fetch/Axios/Undici, Python Requests/HTTPX/Aiohttp, PHP cURL/Guzzle, Go net/http, Java & C# HttpClient, Ruby Net::HTTP, and Rust Reqwest).

## Installation

Install it directly from PyPI:

```bash
pip install omnirequest
```

## Usage

Run the tool from your terminal:

```bash
http-converter
```

Then open your browser at `http://127.0.0.1:5001`.
